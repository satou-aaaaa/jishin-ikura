# 地震保険料控除いくら？（jishin-ikura）

1年に払った地震保険料・旧長期損害保険料・ふつうの火災保険料の場面を読んで、地震保険料控除の額を当てる1日5問の学習ゲーム。正解したら「どの決まり？」（地震保険料・旧長期損害保険料・両方を足す・1つの契約で両方・対象にならない）も選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/jishin-ikura/>

- 答えは、国税庁のタックスアンサーの表から出しています（［令和8年4月1日現在法令等］。2026-11-17 に読みました）（地震保険料は5万円まで全額・超えると5万円。旧長期損害保険料は1万円まで全額・2万円まで半分＋5,000円・超えると1.5万円。両方は合計で最高5万円。1つの契約で両方ならどちらか一方。ふつうの火災保険料は入らない）。
  - No.1145 地震保険料控除 <https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1145.htm>
- 旧長期損害保険料は、平成18年12月31日までに結んだ・満期返戻金があり10年以上・平成19年1月1日以後に変えていない契約だけです。税額・対象になる家屋や家財・剰余金・住民税・申告の手続きは出しません。人と金額はつくりものです。
- このゲームは地震保険料控除のしくみを知る練習です。税の相談の代わりではありません。実際の控除の額は、国税庁の資料や税務署で確かめてください。
